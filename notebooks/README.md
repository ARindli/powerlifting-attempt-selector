# Notebooks

Utforsking og eksperimenter. Nummerer dem i rekkefølgen i livssyklusen, for eksempel:

1. Levedyktighetssjekk
2. EDA
3. Feature engineering
4. Baselines
5. Modellutforsking
6. Finjustering og kalibrering
7. Endelig evaluering og feilanalyse

Kode som skal gjenbrukes (pipeline, features, trening) flyttes til `src/` når den er stabil.
